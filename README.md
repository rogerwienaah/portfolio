# Roger Wienaah — personal site

Plain static site (HTML + CSS + a little JS, no build step). Open `index.html` in a browser to preview.

- Pages: index, experience, projects, awards, gallery, contact, 404 (blog.html is hidden from the menu for now)
- Styles: assets/css/style.css (accent colour = `--accent`) · Script: assets/js/main.js
- Images: assets/img/ · Project papers/slides and resume: docs/ · Videos: videos/
- Hosting: GitHub Pages from this repo (`main` branch), custom domain in `CNAME` (rogerwienaah.com).
